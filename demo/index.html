Draw a patient pathway. Get a Synthea module.

An extension for bpmn.io that lets you model clinical patient pathways in BPMN and convert them into Synthea modules, so you can simulate synthetic patient populations that follow your pathway.

What it is

Synthea describes a disease course as a JSON state machine. That is precise, but hard for clinicians to read and review. Here the diagram stays the source: you model the pathway in BPMN, attach the Synthea settings to each element, and the converter produces the JSON. The settings live only in extensionElements under their own synthea: namespace, so the BPMN itself stays standard.

In the BPMN file

<bpmn:task id="Task_Wait" name="Wait until age 45–65">
  <bpmn:extensionElements>
    <synthea:stateTypeConfig stateType="Delay" />
    <synthea:delayConfig delayShape="RANGE"
      delayValue="45" delayValueHigh="65"
      delayUnit="years" />
  </bpmn:extensionElements>
</bpmn:task>

Becomes this Synthea state

"Wait until age 45–65": {
  "type": "Delay",
  "range": {
    "low": 45,
    "high": 65,
    "unit": "years"
  }
}

How it works

Four steps, each with a tool that checks the result.

  1. ModelDraw the pathway in the bpmn-js modeler and fill in the synthea: properties panel.
  2. Validatebpmnlint rules check the Synthea semantics that the BPMN schema cannot express.
  3. ConvertThe converter writes Synthea modules. It runs in the browser or on the command line.
  4. SimulateRun the modules in Synthea to generate synthetic patients.

What you can use it for

Synthetic cohorts along a pathway

Generate patient populations that follow a modeled clinical pathway, such as lung cancer, for tests and demos without real patient data.

Reviewable pathway models

Let clinicians read and discuss the pathway as a diagram, while the JSON is produced from it instead of written by hand.

Automatic model checks

Find missing fields, broken branches and unsupported constructs before Synthea runs, with an explanation for each message.

A pattern for your own extension

The repository is also a template for custom BPMN extensions: model descriptor, lint plugin, editor module and checks.
