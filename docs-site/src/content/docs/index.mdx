An extension for [bpmn.io](https://bpmn.io) that lets you model clinical patient pathways in BPMN
and convert them into [Synthea](https://github.com/synthetichealth/synthea) modules, so you can
simulate synthetic patient populations that follow your pathway.

## What it is

Synthea describes a disease course as a JSON state machine. That is precise, but hard for clinicians
to read and review. Here the diagram stays the source: you model the pathway in BPMN, attach the
Synthea settings to each element, and the converter produces the JSON. The settings live only in
`extensionElements` under their own `synthea:` namespace, so the BPMN itself stays standard.

In the BPMN file:

```xml
<bpmn:task id="Task_Wait" name="Wait until age 45–65">
  <bpmn:extensionElements>
    <synthea:stateTypeConfig stateType="Delay" />
    <synthea:delayConfig delayShape="RANGE"
      delayValue="45" delayValueHigh="65"
      delayUnit="years" />
  </bpmn:extensionElements>
</bpmn:task>
```

It becomes this Synthea state:

```json
"Wait until age 45–65": {
  "type": "Delay",
  "range": { "low": 45, "high": 65, "unit": "years" }
}
```

## How it works

Four steps, each with a tool that checks the result.

1. **Model.** Draw the pathway in the bpmn-js modeler and fill in the `synthea:` properties panel.
2. **Validate.** bpmnlint rules check the Synthea semantics that the BPMN schema cannot express
   ([lint rules](/convert/lint-rules/)).
3. **Convert.** The converter writes Synthea modules. It runs in the browser or on the command line
   ([converter overview](/convert/converter-overview/)).
4. **Simulate.** Run the modules in Synthea to generate synthetic patients.

## Is it a good fit?

| You want to… | Fit |
|---|---|
| Create Synthea modules from a BPMN pathway | **Yes**, this is the core use case |
| Edit Synthea settings in a bpmn-js properties panel | **Yes** |
| Check a pathway model before running Synthea | **Yes** |
| Convert a Synthea module back into BPMN | Not included |
| Execute or simulate the BPMN process itself | No, Synthea does the simulation |
| Produce data about real patients | No, the output is synthetic |

This is research software under active development. Check the
[issues](https://github.com/forschungsgruppe-digital-health/bpmn-extension-synthea-module/issues) before
you depend on it.
